# 今日人品+ (astrbot_plugin_jrrp_plus)

AstrBot 今日人品 & 塔罗牌全牌占卜插件。

## 功能

### 今日人品

| 命令 | 说明 |
|------|------|
| `/jrrp` | 查看今日人品值（1-100），每个用户每天固定 |

人品值按加权随机分布，中间段概率高、两极概率低。人品值 100 有特殊彩蛋。

### 塔罗牌占卜

包含完整的 **78 张塔罗牌**（22 张大阿尔卡纳 + 56 张小阿尔卡纳），每张牌均有正位/逆位（30% 概率逆位）双寓意。

| 命令 | 牌阵 | 张数 |
|------|------|------|
| `/tarot` | 单张牌占卜 | 1 张 |
| `/tarot3` | 三牌阵（过去·现在·未来） | 3 张 |
| `/tarot_celtic` | 凯尔特十字阵 | 10 张 |

塔罗占卜**每种牌阵每天独立限抽一次**，同一天内你可以分别抽取单张牌、三牌阵和凯尔特十字阵，互不影响。

### 组合指令

| 命令 | 说明 |
|------|------|
| `/daily` | 一次输出人品值 + 塔罗指引 |

## 文件结构

```
astrbot_plugin_jrrp_plus/
├── main.py          # 插件入口，命令调度
├── tarot.py         # 78 张塔罗牌 + 牌阵逻辑
├── jrrp.py          # 人品值生成
├── daily_tarot.py   # 每日抽牌结果持久化
└── metadata.yaml    # 插件元数据
```

## 安装

1. 将本仓库克隆/下载到 `AstrBot/data/plugins/` 目录下
2. 在 AstrBot WebUI 中重载插件
3. 发送 `/jrrp` 查看人品值，发送 `/tarot` 抽取塔罗牌

## 数据存储

塔罗牌每日抽取记录存储在 `data/jrrp_plus/` 目录下，按 `YYYYMMDD_userid_{牌阵}.json` 格式保存，每种牌阵独立记录，跨天自动重置。
